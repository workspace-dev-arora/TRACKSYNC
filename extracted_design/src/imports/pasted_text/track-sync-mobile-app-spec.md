Create a high-fidelity mobile application for the same product “TrackSync”.

TrackSync is an AI-powered maintenance block planning and coordination platform designed specifically for Indian Railways.

This mobile application is used by:
1. Departmental Maintenance Supervisors
2. Field Engineers / Maintenance Staff

This is NOT a scaled-down desktop dashboard.

It is a FIELD-FIRST operational application.
